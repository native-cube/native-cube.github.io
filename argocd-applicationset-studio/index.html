Preview capabilities and limits

The studio models common ApplicationSet behavior without contacting Argo CD, Kubernetes, Git, or an SCM provider. List, mock Cluster, mock Git directory/file, Matrix, and Merge generators are evaluated locally. Unsupported generators can be supplied through generatorResults mock data and are marked as mocked.
